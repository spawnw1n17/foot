# ⚽ Футбольный Симулятор 11x11 Online

Браузерный футбольный симулятор с современным функционалом на русском языке.

## 🎮 Возможности

### Управление командой
- **Состав команды**: Генерация игроков с уникальными характеристиками
- **Тактические схемы**: 4-4-2, 4-3-3, 3-5-2, 5-3-2
- **Визуализация поля**: Отображение расстановки игроков
- **Развитие игроков**: Тренировки и улучшение характеристик

### Матчи
- **2D визуализация**: Реалистичное поле с игроками и мячом
- **Управление в реальном времени**: Пас, удар, отбор, спринт
- **Тактические настройки**: Стиль игры и темп матча
- **ИИ противника**: Адаптивная сложность (легко/нормально/сложно)
- **События матча**: Голы, пасы, отборы с комментариями

### Турнирная система
- **Турнирная таблица**: Отслеживание результатов
- **Рейтинг команды**: Динамическое изменение после матчей
- **Награды**: Монеты за победы и ничьи

### Магазин
- **Новые игроки**: Покупка футболистов
- **Тренировки**: Улучшение характеристик
- **Кастомизация**: Форма команды, стадион

### Прогресс
- **Сохранение**: Автоматическое сохранение в localStorage
- **Уровни**: Прокачка через сыгранные матчи
- **Статистика**: Победы, поражения, ничьи

## 🚀 Запуск

Откройте файл `index.html` в любом современном браузере:

```bash
# Локальный сервер (рекомендуется)
python -m http.server 8000
# или
npx serve .
```

Затем откройте в браузере: `http://localhost:8000`

## 📱 PWA Support

Приложение поддерживает установку как Progressive Web App (PWA):
- Работает офлайн
- Устанавливается на домашний экран
- Автономный режим отображения

## 🎯 Управление в матче

- **Пас** - передача мяча ближайшему игроку
- **Удар** - попытка забить гол
- **Отбор** - попытка отобрать мяч у соперника
- **Спринт** - ускорение ценой выносливости
- **Тактика** - изменение стиля игры и темпа

## 🏆 Особенности

- **Русский язык**: Полная локализация интерфейса
- **Адаптивный дизайн**: Работа на ПК и мобильных устройствах
- **Современный UI**: Градиенты, анимации, тени
- **Реалистичная физика**: Движение игроков и мяча
- **Система усталости**: Влияние на производительность

## 🔧 Технологии

- HTML5 Canvas для рендеринга матча
- CSS Grid/Flexbox для макета
- Vanilla JavaScript (без фреймворков)
- localStorage для сохранения данных
- RequestAnimationFrame для игрового цикла
