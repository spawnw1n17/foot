# Аврора Полёт

Русскоязычный браузерный симулятор гражданских и условных игровых профилей БПЛА.

## Возможности

- карта OpenStreetMap без внешнего JavaScript-фреймворка;
- выбор стартовой точки, масштабирование и перетаскивание карты;
- 14 игровых профилей с разной динамикой;
- полный цикл: запуск, маршрут, возврат, снижение и посадка;
- ручное управление, автопилот возврата и сенсорный пульт;
- день, сумерки, ночь, туман и ветер;
- телеметрия, заряд, след маршрута, очки и точность посадки;
- адаптивный интерфейс для компьютера и смартфона.

## Управление

- `A / D` или `← / →` — поворот;
- `↑ / ↓` — высота;
- `W / S` — тяга;
- `R` — возврат домой;
- `L` — посадка;
- `P` — пауза;
- `Пробел` — запуск.

## Запуск

Откройте `index.html` через локальный HTTP-сервер. Например:

```bash
python3 -m http.server 8080
```

Игра доступна по адресу `/uav-sim/`.

Военные модели представлены только условными игровыми профилями. Реальные боевые характеристики, вооружение, наведение и поражение целей отсутствуют.
