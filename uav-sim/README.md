# Аврора Полёт

Русскоязычная браузерная игра-симулятор гражданских и условных игровых профилей БПЛА поверх OpenStreetMap.

## Возможности

- 16 аппаратов с разной динамикой, звуком и развитием;
- свободный полёт, обучение, аэросъёмка, поиск, доставка, осмотр, посадка при ветре, аварийный возврат, мониторинг пожара, свой маршрут и ежедневное испытание;
- карьера пилота: уровни, опыт, кредиты, покупки, модернизации, достижения, рекорды и журнал;
- два виртуальных стика, клавиатура, три режима камеры и адаптивный интерфейс;
- ветер, туман, дождь, снег, день, сумерки, ночь и случайные нештатные ситуации;
- OpenStreetMap, поиск мест, масштабирование, собственные точки и повтор маршрута;
- PWA, офлайн-оболочка, сохранение прогресса и настройки качества.

## Управление

- `A / D` или `← / →` — поворот;
- `↑ / ↓` — высота;
- `W / S` — тяга;
- `R` — возврат домой;
- `L` — посадка;
- `P` — пауза;
- `C` — смена камеры;
- `Пробел` — запуск.

Военные модели представлены исключительно условными игровыми профилями. Реальные боевые характеристики, вооружение, наведение, поражение целей и боевые задания отсутствуют.
