# NEON DOMINION

Самостоятельная браузерная RTS о захвате цифровых регионов. Игра использует жанровую механику направления армий между связанными узлами, но имеет собственные карты, код, визуальный стиль, способности, типы баз, кампанию и интерфейс.

## Возможности

- 6 операций русскоязычной кампании и быстрый бой.
- Три активные фракции и нейтральные сектора.
- Пять типов узлов: ядро, фабрика, крепость, ретранслятор и реактор.
- Адаптивный ИИ, меняющий цели по силе и типу сектора.
- Перетаскивание армий мышью и пальцем.
- Способности: Купол, Форсаж, Импульс и Мобилизация.
- Масштабирование карты, пауза, скорости ×1/×2.
- Система звёзд, локальный прогресс и статистика боя.
- Адаптивный премиальный тёмный интерфейс.
- PWA и офлайн-кэш.
- Автоматические тесты движка и Chromium QA.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Открыть `http://localhost:8080/neon-dominion/`.

## Проверка

```bash
cd neon-dominion
npm run check
```
