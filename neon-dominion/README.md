# NEON DOMINION — Free Front

Самостоятельная браузерная RTS о захвате цифровых баз. Версия Free Front использует свободное направление армий: любую собственную базу можно связать приказом с любой целью без фиксированных секторных маршрутов.

## Возможности

- Свободное движение между любыми базами по прямым и изогнутым траекториям.
- Групповой выбор на компьютере и телефоне.
- На мобильном: нажать «Группа», коснуться баз или обвести их рамкой, нажать «Отправить N», затем коснуться цели.
- На компьютере: Shift + клик добавляет базу в группу; перетаскивание от любой выбранной базы отправляет всю группу.
- 6 операций кампании и быстрый бой.
- Три активные фракции, пять типов премиальных баз и нейтральные территории.
- Адаптивный ИИ, способности, прогресс, статистика и звук.
- Новый SVG-фон арены и отдельная векторная графика каждого типа базы.
- Адаптивный интерфейс, PWA и офлайн-кэш.
- Автоматические тесты движка и desktop/mobile Chromium QA.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Открыть `http://localhost:8080/neon-dominion/`.

## Проверка

```bash
cd neon-dominion
npm run check
```
