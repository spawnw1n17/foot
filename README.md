# Aurora Eleven

Современный браузерный футбольный менеджер, вдохновлённый классическими онлайн-играми жанра. Проект использует полностью вымышленные клубы и футболистов и не копирует графику, код или брендинг сторонних игр.

## Возможности MVP

- современная адаптивная панель управления клубом;
- состав из 18+ игроков с рейтингом, энергией, статистикой и стоимостью;
- фильтры, поиск, тренировки и автоматический подбор состава;
- тактические схемы 4-3-3, 4-2-3-1 и 3-5-2;
- настройка ментальности, прессинга, темпа и командных инструкций;
- интерактивная 2D-симуляция матча на Canvas;
- счёт, владение, удары, хроника и ускорение матча;
- трансферный рынок с процедурной генерацией игроков;
- бюджет, рейтинг клуба, болельщики и локальное сохранение прогресса;
- адаптация для компьютеров, планшетов и телефонов.

## Запуск

Никаких зависимостей не требуется.

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

Можно также открыть `index.html` напрямую, но локальный сервер предпочтительнее.

## Структура

- `index.html` — интерфейс приложения;
- `styles.css` — дизайн и адаптивность;
- `app.js` — игровые данные, тактика, трансферы и движок матча.

## Следующий этап

Для полноценной сетевой игры потребуется backend: регистрация, база данных, расписание лиг, серверный матч-движок, аукционный трансферный рынок, PvP, античит и админ-панель.
