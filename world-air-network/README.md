# AeroSphere: Global Routes

Самостоятельная браузерная стратегия о строительстве глобальной пассажирской авиасети. Проект использует жанровую идею транспортного менеджмента, но имеет собственное название, интерфейс, код, экономику и визуальный стиль.

## Что уже работает

- 40 крупных городов на шести континентах.
- Открытие и модернизация аэропортов.
- Строительство маршрутов с ценой, зависящей от расстояния.
- Пассажирские группы с конкретным пунктом назначения.
- Автоматический поиск маршрута с пересадками.
- Очереди, вместимость терминалов и поражение при длительной перегрузке.
- Пять классов самолётов, различающихся вместимостью, скоростью и расходами.
- Доходы, топливные расходы, репутация и кредитный предел.
- Случайные события: инвестиции, рост цен на топливо, туристический сезон, грозы, проверки и инженерные прорывы.
- Четыре постоянных исследования.
- Стратегические цели с денежными наградами.
- Скорости пауза / ×1 / ×2 / ×4.
- Автосохранение в `localStorage`.
- Адаптивный интерфейс для компьютера и мобильных экранов.
- PWA-манифест и офлайн-кэширование.
- Автоматические тесты игрового движка.

## Запуск

```bash
cd world-air-network
npm run start
```

Откройте `http://localhost:8080`.

Прямое открытие `index.html` через `file://` не рекомендуется, поскольку браузеры ограничивают загрузку JavaScript-модулей.

## Проверка

```bash
npm run check
```

Команда проверяет синтаксис JavaScript и запускает тесты на расстояния, стабильность идентификаторов маршрутов, пересадки, открытие аэропортов и симуляцию пассажиропотока.

## Управление

1. Нажмите на город.
2. Откройте аэропорт.
3. Выберите «Создать маршрут» и второй открытый аэропорт.
4. Следите за очередью и вместимостью терминала.
5. Покупайте самолёты, улучшайте аэропорты и внедряйте исследования.

Пробел переключает паузу. `Esc` отменяет создание маршрута и закрывает диалог.

## Публикация на GitHub Pages

В настройках репозитория выберите **Pages → Deploy from a branch**, затем ветку проекта и папку `/root`, либо перенесите содержимое каталога `world-air-network` в отдельный репозиторий.

## Правовой статус

AeroSphere не использует название, логотип, графику, музыку, исходный код или другие материалы Fly Corp. Это независимый прототип в жанре управления транспортной сетью.
